# Contributing

This is primarily a personal portfolio shared as a reusable template — most people will fork it rather than contribute back.

If you find a bug or have a suggestion:
- Open an issue describing it
- PRs are welcome for genuine bug fixes or improvements to the template system (feature flags, data fallbacks, etc.)
- Please don't PR your own personal content changes — fork the repo instead

See [Template.md](Template.md) for how to customize this for your own use.
